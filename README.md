# Adaptronic Eugene Support Archive

Este es un archivo de rescate de la documentación de soporte para Adaptronic Eugene, recuperado de servidores S3 de Amazon.

## Contenido
- Documentación técnica para ECUs Modular y Select.
- Guías de configuración y uso del software Eugene.
- Historial de cambios de firmware.

## Origen
El sitio original en `adaptronicecu.com` ya no existe. Este repositorio busca preservar la información para la comunidad.

## Cómo colaborar
Si tienes manuales, imágenes o información adicional que falte, por favor abre un Pull Request.
